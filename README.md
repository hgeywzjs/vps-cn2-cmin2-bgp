## CN2 GIA、CMIN2、BGP，这些缩写决定的是回程

这些缩写描述的都是同一件事：数据从香港回到大陆时走哪张骨干网。晚高峰卡不卡主要看它，而不是看机房离你多近。

分开说：

- **电信用户看 CN2 GIA（AS4809）**：电信的高端回程网络。搬瓦工的香港 CN2 GIA Ultra 系列（Equinix HK2 机房、1Gbps 端口）2核2G 卖 89.99 美元/月，DMIT 的 Premium 系列 1核2G 卖 79.90 美元/月，都是这一档，贵就贵在回程。
- **联通用户看 AS9929（CUII），移动用户看 CMIN2**：各自运营商的高端池，定位和 CN2 GIA 类似。
- **CMI 是移动的国际出口**：一些商家干脆把三网统一往 CMI 上送，比如 XTOM 旗下的香港 VPS 默认强制三网走 CMI、1Gbps 带宽直连内地；咕咕云的建站型则标着电信CN2 + 联通CUG + 移动CMI 三网直连。
- **BGP 是“自动选路”**：机房同时接入多家运营商，按路由择优。但 BGP 也分三六九等——DogYun 香港MG、Akile HKPlus 这类标明 CUG/CMI 的算直连 BGP；也有标着 1Gbps 大端口的香港 BGP，商家自己都写了“仅适合当地使用”。

实用判断法：套餐页写不出具体线路名、只说“优化线路”的，按最普通的国际线路来预期；给出测试 IP 的，自己 ping 一下，晚高峰再测一次，比任何宣传语都准。

## 便宜香港VPS变慢的两大原因：超卖和“限法”

先说超卖。一台母机塞进远超带宽承载能力的用户，白天一切正常，晚高峰大家一起挤。判断思路可以借用一位长期测评香港机器的站长的总结：路由直连、带宽别太小、价格别低到过分——三条同时满足的，基本不会太差。反过来看，价格明显低于同配置市场价、又强调“大带宽不限流量”的，超卖的概率不小。

再说“限法”。同样是便宜套餐，商家限的东西不一样。野草云同时卖两种思路：100Mbps 端口按月流量计费（380G~700G/月），以及 5Mbps/6Mbps 端口不限流量。前者适合偶尔传大文件、流量峰值高的场景，后者适合长期在线但对速度要求不高的服务。买之前想清楚自己的流量曲线是尖峰型还是平稳型，方向选错了再便宜也别扭。

还有一个反直觉的点：端口大不等于回程好。1Gbps 端口配上“仅适合当地使用”的标注，等于商家自己承认回程不行，这种机器拿来做大陆访客的建站就跑偏了。

## 几个常见问题

不需要。香港不在大陆的备案体系内，域名解析过去就能用，这也是很多人宁可绕开大陆服务器的主要原因。

### 香港VPS延迟多少算正常？

通常接近访问国内网站的水平，明显好于欧美机器。但同一座机房里不同线路的差距可能非常大，与其记数字，不如拿商家给的测试 IP 实测。
